# 首页地球路线展示 — 设计文档

> 状态快照。对应 CLAUDE.md「版本」里的**第二版：旅程首页地图/地球路线展示**。
> 权威数据模型见 [2026-06-30-travel-journal-design.md](2026-06-30-travel-journal-design.md)，本文只覆盖首页地球这一块。

## 1. 目标

把首页 `/` 从「重定向到旅程列表」改成一个**可拖拽旋转的 3D 地球**：

- 默认加载**所有**旅程，在地球上画出每次旅行的城市路线。
- 每段路线（Leg）用**弧线**连接出发城市→到达城市，弧线**浮起有高度**。
- **一眼看清两件事**：这段路属于哪次旅程（弧线颜色）、这段用什么大型交通方式（弧线中点的 emoji 图标）。
- 地球是旅程的一个入口：从这里能跳到某次旅程的详情页。

例：北京 ✈️→ 香港 🛳️→ 冲绳 🚄→ 北京，三段弧线同色（同一趟旅程），中点分别是 ✈️ 🛳️ 🚄。

## 2. 视觉与编码约定

| 元素 | 编码 | 说明 |
|------|------|------|
| 弧线颜色 | **按旅程** | 每次 Trip 一个稳定颜色，同一趟的所有 Leg 同色，一眼成团 |
| 弧线中点 emoji | **按交通方式** | 复用 `TRANSPORT_MODE_EMOJI`（✈️🚄🛳️🚗🚌🚶🧭） |
| 城市点 | 亮点 | 每个出现过的城市一个点，hover 出信息卡 |
| 弧线高度 | 固定/按距离 | 浮起效果，越长的段可略高（实现时定；默认固定高度即可） |

**旅程配色**：按 Trip 的 `start_date` 升序排列后，用一个固定调色板（约 10 色）循环取色，保证同一 Trip 每次刷新颜色一致。调色板定义在前端。

**渲染模式（三种可切换）**：右上角分段开关切换，选择记 `localStorage`，默认 🌍 写实。
- **🌍 写实**：Globe.gl（Three.js/WebGL），单张蓝色写实贴图地球 + 浮起弧线。**离线**。
- **🛰️ 卫星**：仍是 Globe.gl 渲染器，把球面换成 Esri World Imagery 卫星瓦片（免 token）。自绘 LOD 瓦片图层——按相机高度选 Web Mercator 缩放级、只加载视野附近瓦片、相机一动按级重算，可放大到街道级（z≈14）。**需联网**（唯一联网模式；断网时退化为底图 + 弧线）。内置 `globeTileEngine` 封顶 z≈7 故弃用改自绘。
- **🗺️ 矢量**：D3 正射投影，浅色线框地球（海洋圆 + 经纬网格 + 大陆矢量）+ 扁平弧线（贴球面，无高度），切到此模式时地球区背景转浅色贴合站点。**离线**。

三种模式读**同一份** `build_globe_data()` 数据，编码（按旅程上色 + 交通 emoji）与联动（列表 hover 高亮、hover 信息卡）一致；实现上抽成统一渲染器接口（`setFocus/focusView/initialView/resize/pause/resume`），由 `globe-home.js` 调度（写实/卫星是 `globe-gl.js` 的两个变体）。库与离线资源（globe.gl、three、d3、topojson、地球贴图、`land-110m` 地形）**下载到本地** `app/static/vendor/`；three 以 ESM 引入并挂到 `window.THREE`，让 globe.gl 复用同一实例（卫星瓦片材质需要）。除卫星瓦片外均不依赖联网 CDN（纯私人本地站，尽量离线可用）。

## 3. 数据流与后端

新增 service：`app/services/globe.py`
- `build_globe_data() -> dict`：读所有 Trip，产出前端所需的纯数据结构（下方 JSON schema）。
- 只包含**出发和到达城市都有经纬度**的 Leg；缺坐标的 Leg 跳过，并在返回结构里附一个 `skipped` 计数/列表，页面上用一行小字提示（如「3 段路线因城市缺少坐标未显示」）。
- 不在此处做地理编码（geocoding 已有独立 service，坐标缺失属数据问题，不在渲染时补）。

路由：`app/blueprints/main.py` 的 `index()` 改为
```python
return render_template("home.html", globe=build_globe_data())
```
数据以 `{{ globe | tojson }}` 内联进模板，前端 JS 直接读，无需额外 XHR 接口。

### JSON schema（service 产出）
```jsonc
{
  "trips": [
    {
      "id": 1,
      "title": "北京-香港-冲绳",
      "start_date": "2025-10-01",
      "end_date": "2025-10-08",
      "color": "#e8792b",            // 后端按序分配，前端也可覆盖
      "url": "/trips/1",             // 详情页链接
      "modes": ["飞机", "游轮", "火车"],
      "arcs": [
        {
          "from": {"name": "北京", "lat": 39.90, "lng": 116.40},
          "to":   {"name": "香港", "lat": 22.32, "lng": 114.17},
          "mode": "飞机",
          "emoji": "✈️"
        }
      ]
    }
  ],
  "cities": [
    {"name": "北京", "lat": 39.90, "lng": 116.40}
  ],
  "skipped": {"count": 0, "legs": []}   // 缺坐标被跳过的段
}
```
- `cities`：所有出现在被渲染弧线里的城市去重，供 `pointsData`。
- `emoji`：后端用 `TRANSPORT_MODE_EMOJI` 映射好，前端直接贴。

## 4. 前端页面 `templates/home.html`

布局：**左地球 + 右旅程列表**（窄屏下上下堆叠）。

JS 分三块：`globe-home.js`（控制器：解析数据、组织共享结构与联动、切换渲染器）+ `globe-gl.js`（Globe.gl 渲染器，含写实/卫星两个变体）+ `globe-d3.js`（D3 渲染器）。

**地球区**
- 右上角渲染器切换开关（🌍 写实 / 🛰️ 卫星 / 🗺️ 矢量）。
- 每个渲染器把所有旅程的弧线按 trip 颜色画出、城市点、弧线中点 emoji；初始视角自动对准所有城市中心，**不自动旋转**，鼠标拖拽可转。
- **hover 信息卡**：停在城市点→显示城市名 + 途经的旅程；停在弧线→显示旅程名、日期、这段交通方式。

**旅程列表区**（右侧）
- 每项：`■` 色块（trip 颜色）+ 标题（链接到 `/trips/{id}` 详情页）+ 日期区间 + 交通 emoji 串。
- **联动高亮**：hover 某项 → 地球上只亮该 trip 的弧线并旋转对准，其余变淡；移开恢复。反向：hover 地球弧线也会点亮对应列表项。
- 无旅程时：地球仍显示（空），列表位置给出引导文案 + 「创建旅程」链接。

**导航**：`base.html` 顶栏品牌 `✈ 旅行记录` 指向首页地球；「旅程」链接仍指向列表页。其余页面不动。

## 5. 边界与降级

- **城市缺坐标**：该 Leg 不画，计入 `skipped`，页面底部一行小字提示。
- **Leg 缺出发或到达城市**（`from_city`/`to_city` 为空）：同样跳过。
- **无旅程 / 无任何可画弧线**：地球正常渲染，右侧显示引导。
- **贴图/库加载失败**：本地文件基本不会失败；若失败，页面至少展示右侧旅程列表（列表不依赖 Globe.gl）。

## 6. 测试

后端 `build_globe_data()` 逻辑很轻（取数 + 整形），**不走 TDD、不写单测**（本次决定）；靠首页预览人工核对：多旅程配色、缺坐标跳过并提示、emoji 映射、城市去重、空库不报错。前端（home.html / globe.js）纯展示逻辑，同样靠预览核对。

## 7. 不做（YAGNI）

- 不做时间轴动画/飞行动画。
- 不做按国家/年份筛选（列表联动足够）。
- 不在地球页做任何数据编辑。
- 不做渲染时自动补城市坐标。

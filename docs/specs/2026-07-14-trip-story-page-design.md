# 旅程故事页 — 设计文档

> 状态快照。对应 [ROADMAP.md](../../ROADMAP.md) 第三版「回顾·统计·分享」的**核心枢纽：旅程故事页**。
> 权威数据模型见 [2026-06-30-travel-journal-design.md](2026-06-30-travel-journal-design.md)，本文只覆盖故事页这一块。

## 1. 目标

给每个旅程一个**沉浸式的按天回放页**——像读一本游记，而不是像详情页那样面向管理/录入：

- 按天滚动：日期 → 所在城市 → 日记全文 → 当天配图 → 当日花费摘要。
- 左侧小地图全程可见，滚动到哪天就高亮那天所在的城市，「旅程在地图上推进」。
- **纯只读**：无任何编辑/删除入口；编辑仍回详情页。
- 它是第三版三个方向的共同底座：回顾浏览（本期）、全屏演示模式（后续加放映壳）、静态导出（后续同模板渲染成品）。

## 2. 页面布局与视觉

**布局（桌面）**：左图右文两栏。

| 区域 | 内容 |
|------|------|
| 顶部 hero | 旅程标题（大字）+ 一行小字摘要：日期范围 / 同行人 / 里程 / 总花费（人民币） |
| 左栏 ~38%，`position: sticky` | 2D 小地图：本旅程路线 + 城市点，滚动联动高亮（见第 4 节） |
| 右栏 | 按天的内容流，每天一个 section（见下） |

**每天的 section（杂志/游记风）**：

- 标题：`Day N · 日期 · 城市`，大号字。
- 日记正文：衬线字体、加宽行高，按段落渲染。
- 照片网格：当天全部配图，2~3 列网格；点击弹**简易灯箱**（遮罩大图，可左右切换、Esc/点遮罩关闭）。
- 花费行：`今日 ￥xxx`（当日人民币合计）+ **亮点条目**小卡——按折算人民币降序取前 3（不足取实际条数），每张卡：类别图标 + 标题 + 金额。当天无消费则整行不显示。
- **没日记也没照片的天不空着**：收缩成一行紧凑条（日期 · 城市 · 当日花费），保持时间线连续。

**视觉风格**：沿用站点现有色板，排版升级为杂志感（大标题、衬线正文、留白更多）。不引入新 CSS 框架，样式放独立的 `static/story.css`，只故事页引入，不污染全站 `style.css`。

**窄屏降级**：媒体查询下左栏地图变为吸顶横幅（地图在上、内容全宽在下），为后续移动端适配留底。

## 3. 路由与入口

- 新路由 `GET /trips/<trip_id>/story` → `templates/trips/story.html`，蓝图里保持薄路由，数据组装在 service。
- 入口：详情页标题区加「故事页」链接；故事页顶部链回详情页与统计页。
- 无任何 POST；页面上没有表单。

## 4. 小地图（2D 平面）

- **d3 + 现有 vendor 资产**（`d3.min.js`、`topojson-client.min.js`、`land-50m.json`），完全离线，新前端文件 `static/story-map.js`。
- 投影自动 `fitExtent` 贴合**取景城市集**的包围盒（加内边距）。取景目标是「保留沿途城市，只甩掉出发地
  和很远的中转」：① **出发地**（home = 第一段 Leg 的出发城市，通常是北京）默认不参与取景（几乎每程都有，
  不强求体现），除非在那儿住够 2 天；② 其余城市到「目的地核心中位中心」距离 ≤ 20° 就保留——成都/重庆
  (林芝)、名古屋(大阪)、吉隆坡(马来西亚) 这类沿途城市都留在画内，住够 2 天的远途目的地（如阿拉斯加）也留；
  只有又远又没怎么待的中转（如迪拜 27°+、仅 1 天）被甩出。中位中心由「住过的城市」（去掉 home）算，稳健。
  被甩出的城市仍会画出（连线飞出画面外），不影响正文。
- 画：陆地底图 + 路线（Leg 按 seq 顺序连大圆弧线）+ 去重城市点与城市名。城市名**贪心避让**：聚集区
  （林芝/鲁朗/南迦、京都/大阪/奈良等）放不下的标签先藏，避免糊成一团；滚动到的当天城市其标签必显示并置顶。
- **滚动联动**：IntersectionObserver 监听右栏每天的 section，进入视口即高亮当天城市点（放大 + 变色），其余城市点常规态。地图本身**不平移不缩放**，保持稳定。
- 与首页地球无关：这是独立的 2D 组件，不受「首页两渲染器都要支持」约束（那条约定只管首页地球的功能）。

## 5. 数据组装（新 service `services/story.py`）

`story_data(trip)` 返回：

```
{
  days: [ { date, city_name, journal, images[], spend_cny, highlights[] }, ... ],
  map:  { route: [ {from:{lat,lng,name}, to:{lat,lng,name}}, ... ],   # Leg 按 seq
          cities: [ {lat,lng,name,days}, ... ],                       # 去重；days=停留天数
          day_cities: [ {day_index, lat, lng} | null, ... ] }         # 滚动高亮用
}
```

- `spend_cny`：当日 Entry 折算人民币合计；`highlights`：当日 Entry 按折算人民币降序前 3（含类别/标题/金额）。
- 金额换算**复用 `stats.py` 现有口径**（Decimal、`人民币 = 外币 ÷ 汇率`、两位四舍五入），不另写一套。
- 缺坐标的城市：从 `route`/`cities` 里剔除；`day_cities` 与 `days` 按下标对齐，一天一格，该天无城市或城市缺坐标时置 `null`（跳过高亮）。均不影响 `days` 正文。

## 6. 错误与边界

| 情况 | 行为 |
|------|------|
| 旅程无 Leg | 地图不画路线，只画各天所在城市的点 |
| 所有相关城市都缺坐标 | 地图区显示「暂无坐标」占位，正文照常 |
| 旅程一个 Day 都没有 | 显示引导语 + 链回详情页 |
| Day 无城市 | 标题只显示日期，地图联动跳过该天 |
| 日记为空/配图为空/无消费 | 对应块不渲染（见第 2 节紧凑条规则） |

## 7. 测试（TDD）

`tests/test_story.py`：

- **service**：亮点挑选规则（降序前 3、不足取实际、无消费为空）；当日合计换算口径与 stats 一致；缺坐标城市被剔除；无 Leg / 无 Day 的降级数据。
- **路由**：200；日记、照片路径、当日金额出现在响应里；页面不含编辑/删除控件；无 Day 时出现引导语。
- 地图与灯箱 JS 按项目惯例不写前端测试，预览人工核对。

## 8. 明确不做（本期）

- 静态 HTML 导出（后续项，同模板渲染）。
- 日记内文与图片混排（配图固定在天末尾的网格里）。
- 地图平移/缩放动画跟随（保持整程静态贴合，只做高亮）。

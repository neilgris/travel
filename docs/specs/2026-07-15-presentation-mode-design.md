# 全屏演示模式 — 设计文档

> 状态快照。对应 [ROADMAP.md](../../ROADMAP.md) 第三版「展示与分享：全屏演示模式」。
> 底座是旅程故事页，见 [2026-07-14-trip-story-page-design.md](2026-07-14-trip-story-page-design.md)；本文只覆盖放映壳。

## 1. 目标

给故事页加一个**放映壳**：全屏、自动翻页、换城市时 3D 地球沿路线飞行，适合当面展示/投屏。

- **纯前端壳**：零后端改动、无新路由；slides 由 JS 从故事页现有 DOM 与 `data-map` JSON 拼装。
- 与 ROADMAP 定位一致：演示模式是「故事页之上加壳」，将来静态 HTML 导出天然带上放映能力。
- 载体混合：日常正文页配 2D 小地图常驻，换城市时插播全屏 3D 地球飞行过场。

## 2. 入口与壳

- 故事页 hero 区加「▶ 放映」按钮，**有 Day 才渲染**（无 Day 时故事页本来就只显示引导语）。
- 点击进入全屏 overlay（Fullscreen API；被拒绝则降级 `position:fixed` 全视口遮罩，功能不变）。深色背景，光标 3 秒不动自动隐藏。
- 新前端文件 `static/story-present.js`；样式先并入 `story.css`，体量大再拆 `story-present.css`。
- **three / globe.gl 懒加载**：首次点「放映」时才注入 `<script>`（按首页地球同款 vendor 资产），故事页平时不背这份体积。

## 3. 放映编排（slide 序列）

```
开场页 → [Day 1 正文页 → 照片页×M] → (换城市? 3D过场) → [Day 2 …] → … → 结尾页
```

| 页型 | 内容 |
|------|------|
| 开场页 | 3D 地球从远处拉近飞向第一站城市（取第一个**有坐标**的城市；一个都没有则见第 6 节降级），旅程标题 + 日期范围 + 同行人浮现在上层 |
| 正文页（每天一张） | `Day N · 日期 · 城市` 大标题 + 日记正文（衬线大字）+ 当日花费摘要行；右下角 2D 小地图常驻并高亮当天城市（复用 story-map 渲染，抽成可调用函数） |
| 照片页 | 当天配图分组拼贴，见第 4 节 |
| 3D 过场 | 仅当**当天城市 ≠ 前一天城市**时插入：全屏地球，弧线从上一城市生长到新城市，镜头跟随，随后淡入新一天正文页，约 3s |
| 结尾页 | 地球拉远展示全程所有弧线 + 统计摘要（N 天 / N 城 / N km / 总花费CNY），停住不循环，提示「↵ 重播 / Esc 退出」 |

- 没日记没照片的「紧凑天」保留一页正文页（日期/城市/花费），短停留，保时间线连续。
- 城市判断用故事页已有的 `day_cities`（按天下标对齐的坐标数组）。

## 4. 照片分组拼贴

- 每天照片分组进拼贴页：旅程 **≤7 天：每天最多 3 页**；**>7 天：每天最多 2 页**。
- 分页规则：`页数 = min(上限, ceil(张数/4))`，尽量每页 ≤4 张，超上限才往每页多塞。
- 页内布局按张数自适应：1 张全屏（`object-fit: contain` 深底）、2 张对分、3~4 张网格、更多密拼（马赛克网格）。

## 5. 控制与节奏

| 操作 | 行为 |
|------|------|
| 自动播放（默认开） | 正文页：基础 6s + 按日记字数递增，封顶 15s；照片页 5s；紧凑天 3s；3D 过场约 3s 不可跳（可快进见下） |
| 空格 | 暂停 / 继续（暂停时角落显示 ⏸） |
| → / 点击 | 下一页；过场动画中则快进到落点 |
| ← | 上一页；跨城市回退直接切，不倒放过场 |
| Esc | 退出放映，回到故事页对应那天的滚动位置 |
| 界面 | 右下角 `Day 3 · 5/28 页` 指示 + 底部细进度条 |

## 6. 边界与降级

| 情况 | 行为 |
|------|------|
| 换城市但任一端缺坐标 / 旅程无 Leg | 跳过 3D 过场，淡入淡出直切 |
| 所有城市缺坐标 | 开场页不飞地球（静态标题页），全程无过场，小地图隐藏 |
| 旅程无 Day | 「放映」按钮不渲染 |
| Fullscreen API 被拒 | 降级 fixed 全视口遮罩 |
| three/globe.gl 注入失败 | 等同缺坐标降级：直切过场，不阻塞放映 |

## 7. 测试

- 后端零改动、模板只加一个按钮：按项目惯例**不写前端测试、不跑 pytest**；现有 `tests/test_story.py` 的「页面无编辑控件」断言应继续通过（放映按钮是链接/按钮，不是编辑入口）。
- 浏览器预览人工验收：长旅程（多国多城）、单城市旅程、缺坐标场景各过一遍。

## 8. 明确不做（本期）

- 循环播放 / 幻灯片转场特效库（只做淡入淡出 + 地球飞行）。
- 演示配乐、旁白、字幕。
- 移动端放映适配（归「局域网只读 + 移动端适配」那一项）。
- 首页地球「双渲染器」约束不适用于此处：放映壳的 3D 过场是独立组件，只用 Globe.gl 一种实现（同故事页 2D 小地图的先例）。

## 1. 项目定位

一个**纯私人**的旅游记录网站，供作者记录每一次旅行：行程、每天的吃喝玩乐购物住宿交通、花费、配图与日记。

- 无账号系统、无多用户、无对外分享（纯私人）。
- **本地单机运行**，不部署云端（未来可升级）。
- 以文字记录为主，**少量配图**。

## 功能总览（当前已实现）

> **状态快照**：描述网站「现在能干嘛」。功能真正上线/移除时更新，不必每次迭代机械改。

- **首页地球**：可拖拽旋转的 3D 地球（Globe.gl，库与贴图离线落地 `static/vendor/`），默认加载所有旅程，每个 Leg 画成浮起弧线（按旅程上色 + 弧线中点交通 emoji），右侧旅程列表与地球联动高亮，标题链到详情页；缺城市坐标的段跳过并提示。
- **旅程管理**：创建 / 编辑 / 删除旅程（标题、日期、行程段 Leg、同行人、多币种及汇率）；删除级联清除其行程段/天/记录/配图记录；旅程列表卡片概要。
- **行程段 Leg**：有序「出发城市→到达城市 + 出行方式」，城市坐标自动地理编码。
- **每日记录**：按天记录日记 + 当天配图 + 多条 Entry（吃饭/游玩/购物/住宿/交通/其他消费，含标题、金额、币种），同天按添加顺序；Day 支持编辑（日期/城市/日记）与删除（连带其下 Entry、配图一并删除），Entry 支持编辑（含改所属日期）与删除。配图挂在 Day 上，非单条消费。
- **记账文件导入**：旅程详情页可上传记账 App 导出的 `.xls` 文件批量导入 Entry；按日期/分类/币种自动匹配到已有的天，能全部匹配的直接入库，任一字段匹配不上的进入待确认列表，人工选择后再入库。
- **多币种花费**：每旅程声明多外币，选币种时自动联网获取实时汇率（可手动覆盖），记录时按币种下拉录入，统一换算人民币。
- **单旅程统计**：环形图（按类别）+ 按城市 + 每日花费与累计组合图 + Top 10 最贵消费 + 按币种原始汇总。
- **设置**：同行人管理、城市管理（均支持增 / 改 / 删；删除前校验是否被旅程引用，被引用则拒绝。城市可手填坐标或勾选「重新定位」自动地理编码，列表按国家/地区分组展示，无国家归入「未分类」）。
- **图片上传**：Day 配图存本地 `uploads/`（一天可多张，创建当天时或事后追加）。

## 3. 数据模型

### 3.1 表结构

**Trip 旅程**
| 字段 | 说明 |
|------|------|
| id | 主键 |
| title | 标题，必填 |
| start_date | 开始日期，必填 |
| end_date | 结束日期，必填 |
| notes | 备注/简介，选填 |

> Trip 的「城市」和「出行方式」**不单独存储**，由 Leg 推导（见 3.2）。

**Leg 行程段**（有序）
| 字段 | 说明 |
|------|------|
| id | 主键 |
| trip_id | 外键 → Trip |
| seq | 序号，决定路线顺序 |
| from_city_id | 外键 → City，出发城市 |
| to_city_id | 外键 → City，到达城市 |
| transport_mode | 枚举：飞机/火车/游轮/自驾/…（可扩充） |

> 不含日期字段，仅靠 seq 排序。

**City 城市**（可跨旅程复用）
| 字段 | 说明 |
|------|------|
| id | 主键 |
| name | 名称，如 札幌 |
| latitude | 纬度（自动地理编码获取） |
| longitude | 经度 |
| country | 国家/地区，选填 |

**Person 同行人**（可跨旅程复用）
| 字段 | 说明 |
|------|------|
| id | 主键 |
| name | 姓名 |
| photo | 照片路径 |

**TripPerson**：Trip ↔ Person 多对多关联表。

**TripCurrency 旅程币种**（一个旅程可多条）
| 字段 | 说明 |
|------|------|
| id | 主键 |
| trip_id | 外键 → Trip |
| currency_code | 币种代码，如 JPY、USD |
| rate | 汇率，方向为 **1 人民币 = ? 外币** |

> 人民币为默认本币，不需在此表登记。

**Day 某天**
| 字段 | 说明 |
|------|------|
| id | 主键 |
| trip_id | 外键 → Trip |
| date | 日期 |
| city_id | 外键 → City，所在城市（选自本旅程 Legs 涉及的城市） |
| diary | 当天日记，选填 |

> 配图挂在 Day 上（见 DayImage），一天可多张。

**Entry 记录条目**（属于某天）
| 字段 | 说明 |
|------|------|
| id | 主键 |
| day_id | 外键 → Day |
| category | 枚举：吃饭/游玩/购物/住宿/交通/其他消费 |
| title | 标题/名称 |
| description | 描述，选填 |
| amount | 金额 |
| currency_code | 币种：人民币或本旅程声明的外币之一 |
| created_at | 创建时间，用于同天排序（按添加顺序） |

**DayImage 配图**
| 字段 | 说明 |
|------|------|
| id | 主键 |
| day_id | 外键 → Day |
| path | 图片路径（一天可多张） |

### 3.2 关键派生与约束

- **旅程涉及的城市** = 所有 Leg 的 from/to 城市去重。
- **旅程的出行方式** = 所有 Leg 的 transport_mode 去重。
- 因此**不需要 TripCity 关联表**。
- **Day 与 Leg 不直接关联**，通过 City 间接相连：Day 选城市时，下拉项 = 本旅程 Legs 中出现过的城市集合。
- **两层分离**：Leg = "怎么走"层（路线/交通/地图）；Day = "每天干了啥"层（日记/记录/花费）。第二版地图只用 Leg，日常记录只用 Day。
- **移动日（如游轮在途）简单处理**：用户自选一个城市（出发地或目的地），不强制 Day 与 Leg 对应，不设"在途"特殊城市类型。

### 3.3 花费换算

- 明细按原币种显示。
- 汇总换算：`人民币金额 = 外币金额 ÷ 汇率`（汇率方向为 1 人民币 = ? 外币）。
- 人民币条目无需换算。

### 3.4 记账文件导入

- 支持记账 App 导出的 `.xls`（老格式）文件，固定列：交易类型/日期/一级分类/二级分类/支出账户/金额/成员/商家/项目/备注。
- 映射：日期→匹配旅程已有的天；一级分类→系统分类（吃饭/游玩/购物/住宿/交通/其他消费）；支出账户→币种（现金→CNY，其余按币种代码，需为本旅程已声明的外币）；备注→标题（描述留空）；金额直接转 Decimal。二级分类/商家/项目/成员列忽略。
- 日期/分类/币种三者全部匹配成功才自动入库；任一匹配失败，整行进入待确认列表，由用户手动补齐失败字段后再入库。
- 不做去重检测（同一文件重复上传会重复入库），不支持 `.xlsx`。

| 页面 | 内容 |

| **首页地球** | 3D 地球展示所有旅程路线（弧线按旅程上色 + 交通 emoji），右侧旅程列表联动高亮、链到详情。详见 [2026-07-08-globe-home-design.md](2026-07-08-globe-home-design.md) |

## 5. 统计（单旅程）

- 仅做**单个旅程**的统计，不做跨旅程全局统计。
- **总花费**：所有条目换算为人民币汇总。
- **按类别**（环形图）：吃饭/游玩/购物/住宿/交通/其他消费，中心叠显总额，tooltip 带占比。
- **按城市**：各城市花费（Day→City 聚合，无城市归「未指定」），金额降序横向条形图。
- **每日花费与累计**（组合图）：柱=当日花费，叠加累计花费折线（右轴）。
- **Top 10 最贵消费**：折算人民币降序取前 10，列出标题/类别/日期/金额。
- **按币种**：各外币原始花费 + 换算后人民币。

图表用 Chart.js，渐变填充 + 圆角 + hover/入场动画（观感增强，不改数据口径）。

## 6. 版本划分

- **第一版**：完整记录流程 + 单旅程统计，旅程页仅列表概要。
- **第二版（已上线）**：首页 3D 地球展示所有行程路线（Leg + City 坐标画弧线），右侧旅程列表联动。详见 [2026-07-08-globe-home-design.md](2026-07-08-globe-home-design.md)。
- **未来增强**：城市坐标自动地理编码若第一版来不及，可先手填、后升级。

## 7. 明确不做（YAGNI）

- 账号系统 / 多用户 / 登录。
- 对外分享 / 评论 / 公开博客。
- 云端部署（第一版本地运行）。
- 自动汇率获取（汇率手动按旅程设置）。
- 跨旅程全局统计。
- 同天记录的时间字段与拖拽排序（按添加顺序）。
